# Contributing

Thanks for your interest in improving Sugar-Coated Mood Journal! We welcome contributions.

Getting started:
1. Fork the repo and create a feature branch.
2. Run `npm install` and `npm start` to verify changes locally.
3. Add tests for new behavior and update existing ones if needed.
4. Open a pull request describing the purpose and changes.

Environment notes:
- Use `.env` to configure whether to use mock Gemini data (`REACT_APP_USE_MOCK=true`) or your own proxy.
